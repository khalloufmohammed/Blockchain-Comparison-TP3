# Blockchain Comparison - TP3

## Project Title
Comparative Study of Public Blockchain, Permissioned Blockchain and Traditional Databases.

## Project Objective
The objective of this project is to understand the differences between three technologies used to store, manage and secure digital information.

## Main Topics
1. Public Blockchain
2. Permissioned Blockchain
3. Traditional Databases
4. Comparative Analysis

## Methodology
This project uses a documentary and comparative approach based on technical concepts, examples and academic sources.
